# 旅First プライバシーポリシー

旅First のプライバシーポリシー・免責事項・著作権・肖像権の取扱いを掲載する静的サイトです。

## ファイル構成

```
index.html   … 本文
style.css    … デザイン
.nojekyll    … GitHub Pages の Jekyll 処理を無効化
```

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成（例: `tabifirst-privacy`、Public）
2. このフォルダの中身（`index.html` / `style.css` / `.nojekyll` / `README.md`）をアップロード
   - ブラウザなら「Add file → Upload files」にドラッグ＆ドロップ
3. リポジトリの **Settings → Pages** を開く
4. **Source** を「Deploy from a branch」、**Branch** を `main` / `/ (root)` にして Save
5. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 文言の修正

本文はすべて `index.html` に直接書かれています。修正後にコミットすれば自動で反映されます。
